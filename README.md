## Selected Projects

### [Uganda Weather](https://www.uganda-weather.com/)

A weather platform focused on providing weather information for locations across Uganda.

- Built with Next.js 15, React 19 and TypeScript.
- Integrated external weather services through APIs.
- Includes forecasts, weather maps and location-based functionality.
- Uses automated testing with Vitest and Playwright.
- Includes Capacitor 7 integration for Android and iOS.

### [Lyia Städ](https://lyia.se/)

A bilingual website developed for a cleaning services company.

- Built with Astro 7 and TypeScript.
- Supports Swedish and English.
- Includes customer-facing booking and enquiry functionality.
- Developed and deployed as a production website.

### [Lyia Braids](https://www.lyiabraids.com/)

A website for a hair salon specialising in braiding services.

- Built with React 19, JavaScript, Vite 8 and Tailwind CSS 4.
- Includes a hairstyle gallery, service catalogue and interactive booking interface.
- Integrates WhatsApp for customer bookings.
- Uses Framer Motion for animations.
